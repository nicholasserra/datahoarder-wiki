# Cloud Service Providers

## [GSuite - Google Drive](https://gsuite.google.ca/intl/en_ca/features/) 

### Features
* $12US/month/user
* Technically unlimited only when having at least 5 users, but this isn't enforced. *Yet?*

### Limitations 
* 750GB upload/24hours
* 750GB download/24hours
* 2 files/per second via API/RClone
